# 🧭 Mahallende Gez

Mahallendeki kahvecileri, parkları, tarihi yerleri ve saklı köşeleri keşfetmeni sağlayan basit bir web uygulaması.

## ✨ Özellikler

- 🔍 Yer, kategori veya mahalle araması
- 🏷️ Kategori filtreleri (Kahve, Yemek, Park, Tarihi, Kültür, Spor)
- ⭐ Puan ve açıklama bilgisi kartlarda
- 📱 Mobil uyumlu (responsive) tasarım
- ⚡ Bağımlılıksız — saf HTML, CSS ve JavaScript

## 🚀 Çalıştırma

Projeyi klonladıktan sonra dosyaları doğrudan tarayıcıda açabilirsin:

```bash
git clone https://github.com/tenisturnuvalari/mahallendegez.git
cd mahallendegez
start index.html
```

Veya yerel bir sunucu ile:

```bash
npx serve .
```

## 📁 Proje Yapısı

```
mahallendegez/
├── index.html      # Ana sayfa
├── css/
│   └── styles.css  # Stil dosyası
├── js/
│   ├── data.js     # Örnek yer verileri
│   └── app.js      # Uygulama mantığı
└── README.md
```

## 🔧 Teknoloji

- CSS3 (değişkenler, grid, flexbox)
- Vanilla JavaScript (ES6)
